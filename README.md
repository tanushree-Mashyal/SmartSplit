SmartSplit

SmartSplit is a web-based expense management application that
helps groups track shared expenses, split bills, manage balances 
and simplify settlements.

Features

- Create and manage groups
- Add group members
- Add and split expenses
- Track individual balances
- Manage settlements
- Persistent data using LocalStorage
- Connected pages for managing group expenses

Tech Stack

Frontend: HTML, CSS, JavaScript
Data Storage: LocalStorage
Backend: Python, Flask (in development)
Database: SQLite, SQL (planned)
Tools: VS Code, Git, GitHub

How It Works

User
  ↓
SmartSplit Frontend
  ↓
HTML + CSS + JavaScript
  ↓
LocalStorage

The project is currently being extended with a Flask backend and will gradually move toward database-backed storage.

Development Roadmap

- Flask REST API
- Frontend–backend integration
- SQLite database
- User authentication
- Multi-user groups
- UPI / payment integration
- Deployment
- Mobile application
